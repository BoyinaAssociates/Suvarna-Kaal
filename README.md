# Suvarna Kaal

Static retirement planner for Boyina Associates. No install or build step.

## Deploy

**Fastest:** open [app.netlify.com/drop](https://app.netlify.com/drop) and drop this whole folder. You get a live URL in a few seconds.

**GitHub + auto-deploy:** push this folder, then connect the repo to [Vercel](https://vercel.com) or [Netlify](https://netlify.com). Leave the defaults (no build command; publish the folder as-is).

Custom domain: Project Settings → Domains (for example `plan.boyinaassociates.com`).
